# Cilantro / Not Cilantro

An iOS app that tells you whether a photo of food contains cilantro. Everything is free: openly licensed training images, Apple Create ML for training, and Core ML for on-device inference (no server).

Built for people with the cilantro aversion gene — for everyone who gets nervous the moment green garnish shows up on food they ordered.

```
scripts/      Python: download, clean and split the dataset
training/     Swift: train the Create ML model
ios/          SwiftUI app (Xcode project generated from project.yml)
data/
  raw/cilantro/        <- images that contain cilantro
  raw/not_cilantro/    <- everything else (especially parsley & other look-alikes)
  attribution.csv      <- source, creator and license of every downloaded image
  split/{train,test}/  <- generated by `make split`
```

## Pipeline

```bash
make setup        # Python venv + deps
make download     # Openverse food/kitchen photos into data/raw/
                  # >>> now REVIEW data/raw/ by hand (see below) <<<
make data         # normalize, de-duplicate, split 80/20 into data/split/
make train        # Create ML -> ios/CilantroCheck/Model/CilantroClassifier.mlmodel
make ios          # generate + open the Xcode project
```

`make train` prints the accuracy on the held-out test set and a confusion matrix. Training takes seconds to a few minutes on a Mac and only needs the Xcode Command Line Tools.

### 1. Collect images

- **Openverse** (`download_openverse.py`): Creative Commons food and kitchen photos, mostly from Flickr and Wikimedia. Labels come from the search query plus a title/tag check, so expect some mistakes. Commercial-use licenses only by default; pass `--allow-noncommercial` for more images if the app stays personal.
- **Your own photos** (the best data): drop them into `data/raw/cilantro/` or `data/raw/not_cilantro/`. HEIC/PNG/JPEG all work; `make data` converts them. Photos of real meals taken with your phone match what the app will see.

Search terms live in `scripts/sources.json`. Add queries and re-run; files you already have are skipped. Wikimedia sometimes rate limits for ~10 minutes; the scripts skip it and continue with other sources.

### 2. Review the images (don't skip this)

Open `data/raw/cilantro` and `data/raw/not_cilantro` in Finder (Gallery view, ⌘4) and delete or move anything mislabeled: a "taco" photo with cilantro on it belongs in `cilantro/`; a "cilantro" photo that's really parsley belongs in `not_cilantro/`. Label quality matters more than quantity.

Aim for **300+ images per label**, roughly balanced. `make data` warns if one label has more than twice as many images as the other.

### 3. Run the app

Requires the full Xcode app (free, Mac App Store) and XcodeGen:

```bash
brew install xcodegen
make ios
```

In Xcode, select the **CilantroCheck** target, open **Signing & Capabilities**, choose your personal team (a free Apple ID works), and change the bundle ID from `com.example.cilantrocheck` to something unique. Run it on your iPhone. With a free account the app must be re-installed from Xcode every 7 days. Publishing to the App Store requires the $99/year Apple Developer Program.

The Simulator has no camera, so the Camera button is disabled there; use **Library** instead. You can drag images onto the Simulator to add them to Photos.

After retraining, just rebuild. Xcode picks up the new `.mlmodel` automatically.

## Improving accuracy

- Hard negatives: parsley-garnished dishes, Thai basil, green onion, mint, arugula.
- Hard positives: small garnish, chopped bits in salsa, cilantro mixed into rice.
- Use photos that resemble real use: plates, bowls, restaurant lighting.
- Check the confusion matrix: cilantro predicted as `not_cilantro` (missed) is the costly error for someone avoiding cilantro. You can raise or lower the 0.5 threshold in `ios/CilantroCheck/CilantroDetector.swift` (`hasCilantro`).
- If tiny garnish keeps being missed, the next step is object detection (Create ML Object Detector) with bounding-box labels.
